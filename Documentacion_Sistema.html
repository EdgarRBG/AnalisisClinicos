Arquitectura del Sistema
Patrón de 3 capas implementado como aplicación de escritorio
Patrón
🏗️ Three-Tier Architecture
Presentación → Lógica de negocio → Datos. La comunicación entre el frontend HTML/JS y el backend Python ocurre a través del bridge window.pywebview.api, que expone métodos Python como funciones JavaScript asíncronas.
Modelo de despliegue
🖥️ Aplicación de Escritorio
La app corre localmente. pywebview incrusta un navegador Chromium que sirve los HTML desde un servidor HTTP interno (Bottle). El ejecutable final se genera con PyInstaller como un solo .exe portable.
